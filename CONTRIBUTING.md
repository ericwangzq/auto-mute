# Contributing

Thanks for your interest in contributing.

## What to work on
- Bugs and reliability issues
- Support for more playback sources
- Power usage optimizations

## Development
1. Build the app:
   ```bash
   scripts/build_app.sh
   ```
2. Run from terminal to see logs:
   ```bash
   build/AutoMute.app/Contents/MacOS/AutoMute
   ```

## Configuration
Config lives at:
`~/Library/Application Support/AutoMute/config.json`

## Code style
- Prefer small, focused changes.
- Avoid adding heavy dependencies.

## Submitting changes
- Use clear commit messages.
- Include logs and reproduction steps for bugs.
